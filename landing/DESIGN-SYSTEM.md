# Дизайн-система лендинга «Домовой»

Три слоя токенов в `styles.css`: примитивы (значения) → семантика (роли) →
компоненты. Компоненты ссылаются только на семантику.

## Палитра

Палитра тёплая: кремовая бумага вместо чистого белого, пастельные заливки из
иллюстраций, тёмно-синий контур `#27313D` как основной цвет текста.

Толщина обводки фокуса во всём проекте — **1px**, как рамка карточки общежития
при наведении. Все поля, кнопки и ссылки используют `--focus-outline-width`;
локальные стили не переопределяют толщину. Токен задан в `frontend/src/index.css`
и продублирован в `landing/styles.css` для самостоятельной сборки лендинга.

**Правило одной кнопки.** Заливкой выделено одно действие на экран — «Запросить
демо». Второе действие в герое — контурное, действия в шапке — служебные.

## Проверенные контрасты

Измерено по формуле относительной яркости WCAG 2.1.

| Пара | Отношение | Норма | Итог |
|---|---|---|---|
| `#27313D` на `#FFFDF9` | 12,98:1 | 4,5:1 | проходит |
| `#4A5A6B` на `#FFFDF9` | 6,51:1 | 4,5:1 | проходит |
| `#27313D` на `#FBF6EC` | 12,24:1 | 4,5:1 | проходит |
| `#4A5A6B` на `#FBF6EC` | 6,57:1 | 4,5:1 | проходит |
| `#FFFFFF` на `#2F7D62` | 4,96:1 | 4,5:1 | проходит |
| `#34679E` на `#FFFDF9` | 5,77:1 | 4,5:1 | проходит |
| `#5B4B9E` на `#FFFDF9` | 7,02:1 | 4,5:1 | проходит |
| `#7B8794` на `#FFFDF9` | 3,60:1 | 4,5:1 | **не проходит** — только плейсхолдеры и декоративные подписи |
| `#C4623C` на `#FFFFFF` | 4,07:1 | 4,5:1 | **не проходит** — только заливки и иконки, не текст |

Тёмный текст на акценте и статусные плашки проверены отдельно; статусы
дополнительно различаются словами, а не только цветом.

## Типографика

Шрифты: **Nunito** (заголовки, 800/900) и **Nunito Sans** (текст, 400/600/700) —
оба с кириллицей. Подключены с Google Fonts, резервный стек — системный.

| Токен | Размер | Роль |
|---|---|---|
| `--text-hero` | 34 → 56px | `h1` |
| `--text-h2` | 26 → 38px | заголовки секций |
| `--text-h3` | 18 → 22px | заголовки карточек |
| `--text-h4` | 17px | пункты FAQ, заголовки шагов, подвал |
| `--text-lead` | 17 → 19px | вводные абзацы, цитаты |
| `--text-body` | 16px | основной текст |
| `--text-sm` | 15px | описания в карточках |
| `--text-xs` | 13px | плашки, подписи, метки |

Правила: интерлиньяж 1,65 для текста и 1,25 для заголовков; `text-wrap: balance`
на заголовках и `pretty` на абзацах; длина строки ограничена 32–46rem;
цифры показателей — `tabular-nums`, чтобы не «прыгали»; прописные метки
(`.eyebrow`) набраны через `text-transform` с трекингом 0,06em.

## Форма элементов

| Токен | Значение |
|---|---|
| `--radius-sm` / `md` / `lg` / `xl` | 12 / 18 / 26 / 34px |
| `--radius-pill` | 999px (кнопки, плашки, дорожки) |
| `--shadow-sm` | мягкая тень карточек |
| `--shadow-md` | подъём карточки и основной кнопки |
| `--shadow-lg` | макет интерфейса и плашки поверх иллюстрации |
| `--section-y` | 56 → 112px — вертикальный ритм секций |
| `--container` | 1140px |

Тени мягкие и низкоконтрастные: стиль плоский, объём создаётся тенью, а не
градиентами. Градиентов в системе нет вообще.

## Сетка и адаптив

- Контейнер 1140px, боковые отступы 18–32px.
- Точки перелома: 1024px (герой в одну колонку, шаги 2×2, отчёт в столбик),
  768px (карточки в один столбик, меню макета — горизонтальное, таблица
  прокручивается), 560px (плашки героя встают под иллюстрацию, футер в столбик).
- Проверено на 1440, 1024, 820 и 520px: горизонтальной прокрутки нет.

## Движение

- Появление секций: 520ms, подъём на 18px, только при
  `prefers-reduced-motion: no-preference`.
- Ховеры: 180–200ms, смена цвета/тени и подъём на 2–3px.
- `scroll-behavior: smooth` для якорных ссылок.
