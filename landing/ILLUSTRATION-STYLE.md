# Стиль иллюстраций — «Домовой»

Единый стиль для всех SVG лендинга. Основа — плоская мультяшная линейная графика:
тёплый тёмно-синий контур + пастельные заливки, без градиентов и теней.

## Правила

1. **Контур** — `#27313D`, толщина 3 (в системе координат 200×200), 4 — в сценах
   800+. Всегда `stroke-linecap="round"`, `stroke-linejoin="round"`.
2. **Заливки** — только пастель из палитры ниже, плоские, без градиентов, теней и
   прозрачностей. Обводка обязательна для каждого замкнутого контура.
3. **Формы** — округлые, «нарисованные от руки»: большие радиусы, мягкие изгибы,
   никаких острых углов и строгой симметрии там, где она не нужна.
4. **Лица** — глаза точками (r 3–4, заливка `#27313D`), брови штрихами, нос мягкой
   дугой, улыбка дугой. Никаких зрачков, бликов и румян.
5. **Пропорции людей** — крупная голова (примерно 1/3 роста), короткие руки без
   кистей-пальцев (ладошка — кружок), обувь — овал.
6. **Фон** — прозрачный. Земля/пол в сценах — тонкая линия `#27313D` или светлая
   полоса `#F4EBDC`.
7. Никаких `<text>`, фильтров, `<image>` и внешних ссылок внутри SVG.

## Волосы персонажей

Тёмные — `#27313D` (заливка сплошная). Светлые/рыжие — `#F2D793`, `#C4623C`,
`#B7D3EC`, `#C6BCE8`, `#F5C0A4`. Каждый персонаж получает свой цвет, чтобы ряд
аватаров читался как разные люди.
