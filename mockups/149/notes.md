# Макет #149 — кабинет оператора: счета

Статичный макет постановки. Открывается двойным щелчком: `mockups/149/index.html`, без сборки,
зависимостей и сети. Экраны — кадры одного сценария в одной странице, сверху вниз.

## Экраны (кадры)

1. **Список · загружен** — шапка с маркой, навигацией из трёх пунктов («Счета» — третий между
   «Организации» и «Пользователи», активен), логином и «Выйти»; заголовок «Счета», счётчик
   `12 счетов` (= `total`), фильтры (поиск, статус, «Сбросить») и реестр из шести колонок:
   № счёта (над ним — ничего, под ним тихая дата), Организация, Предмет (с тихой пометкой
   «Тариф»/«Решение»), Сумма, Статус, действия. В подвале «Показано 6 из 12» и «Показать ещё».
   В кадре все четыре статуса: у `new` — «Скачать счёт», «Отменить», «Оплатить»; у `paid` и
   `closed` — «Скачать счёт» и «Скачать акт», статусных кнопок нет; у `cancelled` — только
   «Скачать счёт».
2. **Список · подтверждение** — первый клик запроса не отправляет: «Оплатить» (или «Отменить»)
   заменяется парой «Подтвердить» / «Не надо» в той же ячейке. Пара одна и та же для обеих
   команд: её место в ячейке и есть контекст.
3. **Список · оплата отправляется** — кнопки строки неактивны и помечены `aria-busy="true"`,
   подписи не меняются, ссылка на счёт остаётся доступной; соседняя строка не блокируется.
4. **Список · отказ действия** — `detail` дословно в `role="alert"` над реестром
   (`operator-invoices-action-error`): «Так нельзя изменить статус счёта». Статус строки,
   фильтры и страница не меняются.
5. **Список · фильтр по статусу** — выбран «Новый», в запросе `status=new`; счётчик показывает
   `total` отфильтрованного ответа (`3 счёта`), «Показать ещё» пропадает. «Сбросить» снимает
   фильтры.
6. **Счетов пока нет** — пустая платформа: счётчик скрыт (`total = 0`), текст объясняет, откуда
   берутся счета.
7. **Ничего не найдено** — пустой результат фильтра: поиск «ромашка» + статус «Отменён»; другой
   заголовок, условия названы в тексте, значения фильтров остались на месте.
8. **Загрузка** — `role="status"`, «Загружаем счета…», счётчик скрыт, фильтры доступны.
9. **Ошибка загрузки** — `detail` дословно в `role="alert"`: «Основной API недоступен». Так же
   выглядят 502 про сервисный токен и 503 про `OPERATOR_SERVICE_TOKEN`.

## Состояния и поведение, видимые в макете

- Видимость действий решают только `status` и `has_act` из ответа: `new` → «Скачать счёт»,
  «Отменить», «Оплатить»; `has_act` → «Скачать акт»; `paid`/`closed` — без статусных кнопок;
  `cancelled` — только счёт. Кнопки «Закрыть» нет.
- Ссылки на PDF — обычные ссылки (`href`), не кнопки: за файлом уходит переход, а не `fetch`.
- «Оплатить» и «Отменить» — двухшаговые: `PATCH` уходит ровно один и только после
  «Подтвердить»; отказ в подтверждении (кнопка «Не надо») возвращает строку в прежний вид.
- Статус — слово из `status_label`, метка (точка) только поддерживает слово формой: контур —
  счёт ещё движется, заливка — решение принято. Цвет не единственный носитель смысла.
- Сумма — `amount_label` дословно («12 400 ₽ за 3 месяца»); не пересобирается из `amount` и
  `currency`. У `new` сумма набрана плотнее — это очередь оператора, у остальных тише.
- Вид предмета (`item_kind`) назван словом «Тариф»/«Решение»: оплата тарифа продлевает
  подписку, оплата решения выдаёт право.
- Поиск — подстрока названия организации или ИНН, регистр не важен, задержка 300 мс; пустые
  `status` и `search` не отправляются. Фильтра по датам, сумме и номеру счёта нет.

## Проверки качества

Клавиатурный фокус: `:focus-visible` — 2px шалфея с отступом 2px; «Подтвердить» нажимается
Enter, фокус остаётся в строке после ответа. Селектор статуса — нативный `select` с
`label`/`htmlFor`, поиск — `type="search"` с подписью для скринридера. Таблица — `<table>` с
`<caption>`, колонка действий без видимой подписи (`visually-hidden`). Контраст текста не ниже
AA. `prefers-reduced-motion` отключает вращение индикаторов, компоновка не меняется. Анимаций
входа и hover-эффектов на строках нет намеренно.

## Что в макет не входит

- Кнопка «Закрыть» (`paid → closed`), откат оплаты (`paid → new`), эквайринг.
- Фильтр по датам и сумме, поиск по номеру счёта, фильтр по организации списком.
- Ссылка «Счета организации» из карточки организации.
- Модальные окна подтверждения и отдельные экраны счетов: карточки счёта нет, строка реестра —
  единственное место действий.
- Журнал действий, письма, уведомления об оплате; роли и права оператора.
- Реальная логика: обработчиков, запросов и состояния в файле нет, только разметка и стили.
