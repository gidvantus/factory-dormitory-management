# Макет #132 — кабинет оператора: пользователи

Статичный макет постановки. Открывается двойным щелчком: `mockups/132/index.html`, без сборки,
зависимостей и сети. Экраны — кадры одного сценария в одной странице, сверху вниз.

## Экраны (кадры)

1. **Список · загружен** — шапка с маркой, навигацией из двух пунктов, логином и «Выйти»;
   заголовок «Пользователи», счётчик `61 пользователь` (= `total`), поле поиска, реестр из пяти
   содержательных колонок: ФИО (над ним тихий номер `№ 142`), Email, Организация, Роль,
   Состояние, действие «Открыть». В подвале «Показано 8 из 61» и «Показать ещё».
2. **Список · загрузка** — «Загружаем пользователей…» в рамке реестра, счётчик скрыт.
3. **Список · пусто** — «Пользователей пока нет»: в базе нет ни одной учётной записи.
4. **Список · ничего не найдено** — «Ничего не найдено» для поиска «щукин»; блок ниже (поиск
   промахивается чаще, чем бывает пустая база), запрос остаётся в поле.
5. **Список · ошибка** — `role="alert"` с текстом отказа дословно: «Основной API недоступен».
   Так же выглядят 502 «Основной API не принял сервисный токен» и 503 про пустой токен.
6. **Карточка · просмотр** — «К списку», ФИО как `h1`, строка «Пользователь №142 · создан
   12 февраля 2026», кнопка «Редактировать», выписка «Учётная запись»: Email, Организация, Роль,
   Состояние («Активирован» с залитой точкой). В подвале выписки — «Правится только ФИО…».
7. **Карточка · правка** — одна карточка: поле ФИО сверху (единственное поле ввода), под ним
   подсказка, read-only строки теми же, что в просмотре, внизу «Сохранить» / «Отмена».
8. **Карточка · отказ 422** — введённое значение осталось (`" "`), поле помечено
   `aria-invalid`, текст «ФИО не может быть пустым» дословно в `operator-user-error` над
   кнопками.
9. **Карточка · «Не активирован»** — тот же экран для `is_active = false`: контурная точка и
   подпись «Не активирован». Никаких пояснений про доступ в интерфейсе нет.
10. **Карточка · 404** — «Пользователь №999999», «Пользователь не найден», пояснение и
    «К списку».
11. **Деталь · отправка правки** — «Сохранить» неактивна, `aria-busy="true"`, текст
    «Сохраняем…»; «Отмена» доступна.

## Состояния и поведение, видимые в макете

- Навигация: «Организации» → `/`, «Пользователи» → `/users`; текущий раздел помечен
  `aria-current="page"` и подчёркиванием 2px шалфея на линии шапки. Цвет в метке не участвует.
- Счётчик в шапке — `total` текущего ответа, скрыт при загрузке и при `total = 0`.
- «Показать ещё» видна, пока `items.length < total`; «Показано N из total» — тихая подпись.
- `organization_name = null` и `role = null` — тире `—` серым, и в списке, и в карточке.
  Слова «без организации» и «нет роли» не выдумываются.
- `is_active` подписан только «Активирован» / «Не активирован»; слово «заблокирован» в макете
  не встречается нигде — это условие контракта, а не стилистика.
- «Отмена» возвращает значение последнего ответа сервера; «Сохранить» отправляет только
  `full_name`.

  «Открыть» в первой строке, ФИО на всю ширину, ниже email, «Организация: …», «Роль: …»,

  строка с ФИО на две строки, email на две и организацией на три).

`panel`, `panel__head`, `panel__title`, `panel__note`, `req*`, `page*`, `link` — те же, что в

Надпись на основной кнопке — тёплый чёрный `#262420` на шалфее (6.0:1).

## Проверки качества

Клавиатурный фокус: `:focus-visible` — 2px шалфея с отступом 2px. Поле ФИО связано
`label`/`htmlFor`, ошибка — `role="alert"` + `aria-describedby`, `aria-invalid` на поле.
`prefers-reduced-motion`: индикаторы не крутятся, компоновка не меняется. Таблица — `<table>` с
`<caption>` для скринридера, колонка действия без видимой подписи (`visually-hidden`).

## Что в макет не входит

- Создание пользователей, приглашения и переотправка письма активации, сброс пароля, блокировка
  и деактивация — кнопок и экранов нет.
- Правка email, роли и организации: в карточке это текст, полей ввода и ручек нет.
- Массовые действия, фильтры по организации/роли/состоянию, сортировка по колонкам, экспорт.
- Журнал действий оператора, тарифы и пробный период, согласия — не показываются.
- Экран входа и состояние «сессия истекла» — без изменений, в макете не показаны.
- Реальная логика: обработчиков, запросов и состояния в файле нет, только разметка и стили.
  Анимаций входа и hover-эффектов на строках нет намеренно.
