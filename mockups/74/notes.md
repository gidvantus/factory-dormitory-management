## Что важно реализовать именно так

- Колонки — ровно четыре, без отдельной колонки времени: время идёт рядом с датой (`28.10.2026 14:32`),
  дата 13px/700, время 12px приглушённое, `tabular-nums`.
- Раскрытие — второй `<tr class="journal-details">` с `<td colSpan={4}>` и нативным `<details>`;
  `<summary>` — строка 27px с шевроном, подписью «Запись журнала» / «Скрыть запись» и номером записи
  справа. Модалку и боковую панель для JSON не делать: ленту нельзя терять из виду.
- JSON — `<pre>` 11px/1.4 моноширинным стеком продукта (`ui-monospace, 'Cascadia Code'`), максимум
  208px по высоте с прокруткой, `white-space: pre-wrap`. В макете ключи идут в порядке
  `id, created_at, changes, action, action_title, kind, status, duration_ms, path, …` — сначала то,
  что читают (изменения), служебное (ip, user_agent, request_id) ниже за прокруткой.
- Теги вида: «Данные» — существующий `.tag--neutral`; «Безопасность» — новый модификатор на
  `--sky-100` / `--blue-600`; «Служебное» — на `--butter-100` / `--butter-700`. Оба значения из `:root`.
- Статус — точка `.status-dot` (7px) + код + время ответа приглушённым: `--color-status-ok` для 2xx,
  `--color-status-missing` для 4xx/5xx, `--color-status-neutral` для пустого.
- Неизвестный код действия выводится сам кодом, моноширинным 12px (`data-unknown="true"`),
  без придуманного названия.
- `data-testid` из постановки уже стоят в разметке: `journal-from`, `journal-to`, `journal-kind`,
  `journal-row`, `journal-more`, `journal-empty`, `journal-forbidden`.
- Иконка `journal` для `WorkspaceIcon.tsx` — «квитанция»: `M5 4h14a1 1 0 0 1 1 1v15l-3-2-3 2-3-2-3 2V5a1 1 0 0 1 1-1Z`
  плюс `M9 9h6M9 13h4`. Пункт «Журнал» — после «Статистики», перед «Магазином улучшений».

## Тексты фильтров

`От`, `До`, `Вид`; варианты вида: `Все действия`, `Безопасность`, `Данные`, `Служебное`;
кнопка `Применить`. Подзаголовок страницы: «Что делали вы и сотрудники организации за выбранный период».

## В макет не входит

- Бизнес-логика, запросы, состояние, обработчики — только вид.
- Правки продуктового кода, `index.css`, схемы, API: всё это следующий шаг, по метке `ready-for-dev`.
- ФИО вместо `actor_id`, снимок «было → стало», фильтры по сотруднику/действию/статусу, экспорт CSV —
  следующий шаг.
- Открытое мобильное меню-оверлей: в кадре только кнопка.
- Шрифты: в приложении Nunito и Nunito Sans приходят ссылкой на Google Fonts; макет открывается без
  сети, поэтому стоит тот же стек, но без загрузки (без установленного Nunito отрисуется Segoe UI).

## Брак

Колонка времени отдельно от даты; карточки вместо таблицы на десктопе; модалка для JSON; цветные
бейджи на всё подряд; чужие радиусы, шрифты, отступы; капс-подписи над заголовками; «Показать ещё»
без «За этот период — N записей»; «Показать ещё» при пустом ответе.
