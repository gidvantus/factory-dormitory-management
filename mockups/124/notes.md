# Макет #124 — тариф организации в левой панели

Статичный HTML, без сборки и сети. Открыть: `mockups/124/index.html` (двойной щелчок). Токены и
размеры скопированы из `app/frontend/src/index.css` и `src/workspace/Workspace.module.css`; шрифты
продукта Nunito / Nunito Sans по сети макет не грузит — при их отсутствии работает запасной стек.

## Оформление и правила

- Высота карточки одна на все состояния — `min-height: 234px` при 212 px ширины; «Загружаем
  тариф…» не дёргает панель. Кнопка прижата к низу (`margin-top: auto`), поэтому в коротких
  состояниях она стоит на одном уровне с остальными.
- Название и дата переносятся: `min-width: 0` + `overflow-wrap: anywhere`. Горизонтальной
  прокрутки нет ни на 212, ни на 196 px.
- Состояние не кодируется цветом: у `locked` и `error` есть свой текст, у `expiring` — вес строки
  остатка и слово кнопки «Продлить тариф».
- Контраст (посчитан): `--violet-600` на `--lilac-200` — 3,98:1, поэтому внутри плашки срока текст
  только `--ink-900`/`--ink-700`; надпись «Текущий тариф» на лиловой подложке — `--ink-500`
  (5,5:1), а не `--color-text-muted` (4,29:1). `--mint-700` на белом — 6,8:1, белый на
  `--mint-600` — 4,97:1.
- Закрытый кабинет говорит на `--butter-100/--butter-200` (как `TrialNotice`), иконка замка —
  `--clay-700` (4,76:1). Состояния без данных («загрузка», «ошибка», «тарифа нет») у вида A
  нейтральные, а не лиловые.
- Фокус: `.shell a:focus-visible, .shell button:focus-visible` — 1 px `--blue-600`, отступ 3 px.
  Анимаций в макете нет, `prefers-reduced-motion` ничего не ломает.
- Брейкпоинты: 1100 px — панель 220, карточка 196; 760 px — панель уезжает в шторку 248 px
  (карточка снова 212). Высота панели проверена на окне 900 px: 5 пунктов меню прокручиваются
  внутри `nav`, карточка и «Выйти» остаются на месте.
- Тариф в кабинете один — «Рост» (`name: 'Рост'`, описание «Все разделы, расширенная отчётность и
  статистика», `price_label: '9 900 ₽ в месяц'`); пример «Расширенный» в узкой панели нужен только
  для проверки переноса длинного имени.

## Что в макет не входит

- Продуктовый код, стили приложения, схему данных и API не трогаем; `/preview/sidebar-tariff`,
  `SidebarTariff.tsx`, переезд testid и правки `TrialNotice.test.tsx` — следующий шаг.
- Не показаны: обработчики, запросы, состояние, порядок загрузки, переходы по `/pricing`,
  мобильная навигация панели, магазин, прайс, `TrialNotice` на закрытом кабинете.
- Второй вид не выбран: выбор за человеком по картинке (стоп-точка этапа 1). Реализуется ровно
  один вид из двух; состояния, тексты, ширина и поведение у них одинаковые.
