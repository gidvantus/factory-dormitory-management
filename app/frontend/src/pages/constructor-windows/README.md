# Конструкторы в привычных отдельных окнах

Тестовая страница: `/preview/constructors-windows`.
`?window=formula` сразу открывает пример редактора формулы,
`?section=arrivals&window=arrival-fields` — настройки заездов.

Отдельный вариант «Настройки + живой результат» находится по адресу
`/preview/constructors-windows-live?window=formula`. Поля располагаются слева,
пересчитываемый черновик — справа в том же окне. На экране до 900px части идут
друг под другом. Все переходы остаются в выбранном варианте стенда.
Для заездов, создания общежития и статистики используется их штатный
предпросмотр; ещё одна панель к нему не добавляется.

Вариант сохраняет модальную схему проекта. На фоне остаётся текущий раздел,
редактор открывается поверх него и после сохранения возвращает пользователя к
данным. Заголовок остаётся видимым, кнопки формы закреплены внизу при прокрутке.
В редакторе строки способы заполнения представлены отдельными вариантами выбора.
Пример результата раскрывается по желанию внутри окна.

Действующие редакторы используются без удаления полей и операций. Доступны
общий отчёт (все типы строк, формулы, связи, размещение, шаблоны), структура
общежития, создание общежития, вкладки, таблицы, столбцы, связь с персоналом,
рабочие блоки и сохранённые списки, оба раздела настроек заездов, дашборд и
статистика. Редактор блока статистики также открывается окном.

`EditorSurfaceContext.windowed` и `intro` включают оформление и пояснения только
на этом стенде. Обычный кабинет и прежний вариант страницы сохраняют своё
поведение. Для примеров используется локальное хранилище `constructor-sandbox`:
сохранение действует до перезагрузки, запросы в рабочую базу не отправляются.

Интерактивные проверки покрывают загрузку 13 отдельных окон без сети, сохранение
сложной формулы с необязательным предпросмотром, обе вкладки заездов и полный
редактор статистики внутри диалога.
