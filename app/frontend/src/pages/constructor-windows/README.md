# Конструкторы в привычных отдельных окнах

Новая организация: `/preview/constructors-organized?window=formula`.
Переключатель «Сейчас в проекте / Предлагаемая организация» сравнивает одни
и те же действующие формы на одинаковых тестовых данных. Переключение доступно
на странице после закрытия окна; сохранённые данные при сравнении остаются.

В новом варианте длинные формы получают смысловые разделы и оглавление с
прокруткой. Поля остаются в одной форме, сохраняются одной кнопкой и не
размонтируются при переходе по оглавлению. На узком экране оглавление расположено
над формой; заголовок и действия доступны при прокрутке.

- Строка отчёта: название → способ заполнения → выражение либо источник,
  условие и дата. Полное выражение со всеми действиями редактируется в textarea;
  строки и операторы вставляются вместо выделения или в позицию курсора.
  Доступен поиск среди строк. Удаление вынесено в отдельную группу.
- Вкладки: основа → название и подвкладки → вид → даты и период → действия.
  Столбцы: название → тип → условные варианты списка. При создании таблицы
  можно заранее менять порядок столбцов.
- Персонал: данные сотрудника, даты вахты и статус разделены в привязках;
  рабочие блоки и сохранённые списки сгруппированы по назначению и условиям.
- Заезды: сохранены две штатные вкладки «Поля формы / Правая панель», все семь
  типов, значения на заезд и на человека, ограничения использованных полей,
  видимость, обязательность, порядок и настройки карточек.
- Дашборд: название → источник и расчёт → общежития → отображение → проверка.
  Статистика, дерево структуры, управление вкладками, архивы и шаблоны сохраняют
  свои существующие редакторы и операции.

`EditorSurfaceContext.organized` включает эти изменения только на новом стенде.
`EditorSection` вне этого контекста возвращает исходные дочерние элементы.
Обычный кабинет сохраняет прежние формы. Проверки нового варианта находятся
в `OrganizedWindows.test.tsx`: отдельные окна без сети, сравнение вариантов,
сохранение и вставка сложной формулы, условные поля, обе вкладки заездов,
привязки персонала, порядок столбцов и организация дашборда.

Тестовая страница: `/preview/constructors-windows`.
`?window=formula` сразу открывает пример редактора формулы,
`?section=arrivals&window=arrival-fields` — настройки заездов.

Отдельный вариант «Настройки + живой результат» находится по адресу
`/preview/constructors-windows-live?window=formula`. Поля располагаются слева,
пересчитываемый черновик — справа в том же окне. На экране до 900px части идут
друг под другом. Все переходы остаются в выбранном варианте стенда.
Для заездов, создания общежития и статистики используется их штатный
предпросмотр; ещё одна панель к нему не добавляется.

Вариант сохраняет модальную схему проекта. На фоне остаётся текущий раздел,
редактор открывается поверх него и после сохранения возвращает пользователя к
данным. Заголовок остаётся видимым, кнопки формы закреплены внизу при прокрутке.
В редакторе строки способы заполнения представлены отдельными вариантами выбора.
Пример результата раскрывается по желанию внутри окна.

Действующие редакторы используются без удаления полей и операций. Доступны
общий отчёт (все типы строк, формулы, связи, размещение, шаблоны), структура
общежития, создание общежития, вкладки, таблицы, столбцы, связь с персоналом,
рабочие блоки и сохранённые списки, оба раздела настроек заездов, дашборд и
статистика. Редактор блока статистики также открывается окном.

`EditorSurfaceContext.windowed` и `intro` включают оформление и пояснения только
на этом стенде. Обычный кабинет и прежний вариант страницы сохраняют своё
поведение. Для примеров используется локальное хранилище `constructor-sandbox`:
сохранение действует до перезагрузки, запросы в рабочую базу не отправляются.

Интерактивные проверки покрывают загрузку 13 отдельных окон без сети, сохранение
сложной формулы с необязательным предпросмотром, обе вкладки заездов и полный
редактор статистики внутри диалога.
