# Полные конструкторы проекта: вариант №2

Тестовая страница: `/preview/constructors-project`.

Страница использует действующие компоненты приложения. Контекст
`EditorSurfaceContext` встраивает обычные модальные редакторы в страницу и
передаёт их черновик предпросмотру. Вне контекста редакторы работают как прежде.
В составных редакторах сохранён их собственный предпросмотр.

## Данные и границы стенда

`api.ts` временно подменяет методы `api`, `statisticsApi`, `personnelApi` только
на время существования страницы и восстанавливает их при выходе. Обращения к
неподдержанному методу завершаются ошибкой, а не запросом к рабочему серверу.
Стенд не создаёт аккаунты, не меняет рабочие общежития и не публикуется автоматически.

Три демонстрационных общежития, записи, сотрудники, хостелы, заезды, шаблоны и
отчёты находятся в памяти страницы. Изменения сохраняются при переходах между
конструкторами, перезагрузка возвращает начальные данные. Серверные операции
моделируются локально; это не интеграционный тест базы данных или прав доступа.

Для предпросмотра формул используется безопасный арифметический парсер с теми же
операциями, что в `app/backend/app/report_formula.py`. Вычисляется каждая дата;
пустые ячейки считаются нулём, ошибки показываются в результате.

## Проверки

`sandbox.test.ts` проверяет вычисления, зависимости, сохранение и восстановление
столбцов, копирование, шаблоны, источники, группировки, итоги, расположение блоков,
связь с персоналом и отсутствие сетевого перехода для неизвестных методов.
`ConstructorSandbox.test.tsx` открывает все 19 сценариев и проверяет реальные
формы: сложную формулу, оба раздела заездов, связанную строку размещения, варианты
столбца, десять фильтров и каталог источников статистики.
