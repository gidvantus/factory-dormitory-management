# Примерочная «Обзора»

Локальная тестовая страница: `/preview/overview`. Вариант задаётся адресом
`?variant=1` … `?variant=5`, все вместе — `?variant=all`.
Рабочий обзор и серверные данные не меняются. Данные и статусы вымышлены.

## Направления оформления

Общая основа сохраняет оформление «Домового»: Nunito для заголовков и чисел,
Nunito Sans для текста. Палитра: чернильный `#263849`, белый `#ffffff`,
мятный `#2d8069`, голубой `#427caf`, ореховый `#9b6544`, сиреневый `#7a65ab`.
Цвет общежития одинаков в списках, диаграммах и иллюстрациях.
Текст и подписи выровнены влево; центральное выравнивание — у домиков и колец.

1. **Живой квартал**: `[иллюстрация квартала] / [сводка × 3] / [график | дома]`.
   Главный образ — несколько домов; визуальный язык продолжает «Персонал».
2. **Аналитика**: `[сводка] / [кольцо | большой график] / [сравнения | отчёты]`.
   Цвет кодирует долю конкретного общежития, а не украшает одинаковые карточки.
3. **Пульт руководителя**: `[контрастная сводка с мини-графиками] / [динамика] / [детали]`.
   Тёмный бирюзовый акцент сосредоточен в одной сводке; остальная страница светлая.
4. **Лента дня**: `[проживание] → [работа] → [отчёты]` по вертикали.
   Повествование строится вокруг рабочих вопросов, а не сетки одинаковых блоков.
5. **Атлас общежитий**: `[сводка] / [дом с показателями | дом с показателями] / [общая динамика]`.
   Единица обзора — само общежитие со своим цветом и домиком.

Вместо пяти перекрашенных копий используются пять разных композиций.
Общие фильтры и одинаковые значения позволяют сравнивать именно оформление.
Иллюстрации выполнены в SVG без внешних сервисов и загрузок.

## Поведение

- Фильтры меняют период и общежитие во всех вариантах. Карточки показывают срез
  на 2 ноября или 31 октября 2026, графики — дневную численность за период.
- Статусы отчётов относятся к 2 ноября независимо от периода графика.
- На графике можно переключать проживание, выход и текучку.
- Нажатие на общежитие открывает демонстрационную карточку.
- «Мне нравится» сохраняет один отмеченный вариант только в localStorage браузера.
- «Посмотреть без данных» показывает отсутствие показателей без фиктивных нулей.
- На узком экране блоки располагаются вертикально. Графики имеют текстовые
  описания, кнопки — состояния, клавиатурный фокус видим.
