# Настройка заполнения ячеек

Локальная тестовая страница: `/preview/cell-fill`.

Пример подвкладки «Отпуск» показывает три способа заполнения: вручную, выбор
записи из другой таблицы и подстановка значения из выбранной записи. Название
подвкладки, названия, типы и состав столбцов меняются в конструкторе. Для связи
выбираются таблица, совместимый по типу столбец и столбец выбора человека.
Доступны демонстрационные «Проживающие» и «Сотрудники».

По умолчанию ФИО выбирается из «Проживающих», дата заселения берётся из той же
записи, даты отпуска заполняются вручную. Связь хранит ID записи: два одинаковых
ФИО различаются по табельному номеру. При удалении/изменении столбца выбора
проверяются зависимые связи. Некорректную конфигурацию применить нельзя.

В режиме «Обновлять автоматически» ячейка читает актуальное значение. В режиме
«Скопировать один раз» значение фиксируется при выборе человека; смена человека
или правила связи создаёт новую копию. Раскрытая таблица-источник позволяет
изменять и очищать даты для проверки обоих режимов. Связанные ячейки доступны
только для чтения; ручные значения сохраняются при переключении способов.

«Применить настройки» закрывает конструктор, «Настроить подвкладку» возвращает
его. Добавление/удаление строк и сброс работают только с вымышленным примером.
Все изменения находятся в памяти до перезагрузки. API и рабочие конструкторы
не изменяются. Это прототип поведения, без серверного сохранения и синхронизации.
