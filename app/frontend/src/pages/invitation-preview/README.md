# Пять вариантов письма-приглашения

Локальная тестовая страница: `/preview/invitations`. Доступна без входа.
Пять макетов адаптируют структуру двух предоставленных скриншотов к «Домовому».
Демонстрационные имя, организация, адрес и ссылка одинаковы во всех вариантах.
Страница не обращается к API приглашений и не отправляет письма.

## Дизайн

Общая палитра проекта: чернильный `#27313d`, белый `#ffffff`, мятный
`#dceee4`, зелёный `#2f7d62`, голубой `#dce9f7`, сиреневый `#e6e1f5`.
Оболочка использует фирменные Nunito / Nunito Sans, письма — Arial с системными
резервными шрифтами. Основной текст выровнен влево; открыточный вариант — по центру.

1. **По вашему образцу**: `[тёмный логотип] / [тёмная шапка] / [текст, шаги, кнопка] / [тёмный подвал]`.
   Сохраняет композицию референса, переводит акценты в фирменный зелёный.
2. **Добро пожаловать домой**: `[логотип] / [мятная шапка с домом] / [текст, шаги] / [кнопка, подпись]`.
   Главный образ — открытая дверь общежития, мягкие цвета существующего сайта.
3. **Только главное**: `[логотип] / [короткое приглашение] / [организация] / [кнопка] / [три шага]`.
   Короткое деловое письмо с голубым акцентом и действием перед инструкцией.
4. **Тёплая открытка**: `[домики] / [центрированный заголовок] / [приветствие] / [три шага в ряд] / [кнопка]`.
   Пастельная иллюстрация связывает приглашение с предметом проекта.
5. **Ваш пропуск в команду**: `[логотип] / [заголовок] / [пропуск: организация и получатель] / [кнопка, шаги]`.
   Приглашение оформлено как персональный пропуск с перфорацией.

Проверка замысла: варианты отличаются композицией и порядком подачи информации,
а не только цветом. Во всех сохранены назначение письма, персональное обращение,
организация, три шага активации, основная и резервная ссылки, срок и подвал.

## Поведение и границы

- Выбор макета отражается в `?variant=1` … `?variant=5`, поддерживает прямые ссылки.
- Можно открыть все пять писем и переключить ширину выбранного письма на 375 px.
- Отмеченный вариант хранится только в localStorage этого браузера.
- Кнопка приглашения и резервная ссылка открывают пояснение о демонстрации.
  Они не создают пользователя и не используют рабочие токены.
- HTML писем изолирован в iframe; кнопки управления не входят в само письмо.
- Срок 24 часа — демонстрационное значение по умолчанию из конфигурации проекта.
  Внедрение выбранного макета в SMTP и подстановка реального срока — отдельная задача.
- Это визуальные HTML-макеты. Совместимость с Outlook и другими почтовиками
  предстоит проверять при внедрении выбранного варианта; иллюстрации пока в SVG.
