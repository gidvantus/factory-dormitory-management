# Вариант №2 внутри кабинета

`/preview/constructors-project` — отдельный локальный макет, показывающий подход
«Настройки + результат» в оформлении действующего кабинета «Домовой».
Используются стили оболочки `workspace/Workspace.module.css`, существующие
иконки и иллюстрации. Компоненты полей, коллекций и результатов взяты из
`constructor-lab`, чтобы демонстрации оставались согласованными.

По умолчанию открыт редактор статистики. В меню доступны «Обзор», «Общежития»,
«Персонал» и «Статистика» с точками входа во все 12 конструкторов. Раскрывающийся
список «Открыть другой конструктор» позволяет перейти к нужному примеру напрямую.
Параметр `builder` открывает редактор, параметр `section` — раздел.

Настройки меняют предпросмотр сразу. «Что изменится» сравнивает черновик с
сохранённым состоянием. Сохранение возвращает в раздел и показывает обновлённый
результат. При выходе из изменённого редактора можно сохранить, отказаться от
правок или продолжить настройку. Перед перезагрузкой работает предупреждение.

Макет не подключён к API. Все данные вымышлены; состояние и сохранения живут
в памяти страницы до перезагрузки. Это пример интеграции интерфейса, а не
подключение нового редактора к рабочим данным.

Проверки из `app/frontend`: `npm run test -- src/pages/constructor-project-preview
src/pages/constructor-lab`, затем `npm run build`.
