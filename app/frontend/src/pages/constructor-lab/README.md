# Тестовая мастерская конструкторов

Адрес: `/preview/constructors`. Страница доступна без входа, загружается отдельным
пакетом и использует только вымышленные данные. Она не импортирует API и не
сохраняет настройки кабинета. Черновики, история отмены и применение в примере
хранятся в памяти до перезагрузки. Параметры `builder` и `variant` позволяют
открыть конкретный сценарий по ссылке.

Пять подходов: пошаговый мастер, настройки с результатом, готовые примеры,
читаемое правило, редактирование через области результата. Каждый доступен для
всех двенадцати сценариев:

| Сценарий                | Текущие компоненты проекта                                             |
| ----------------------- | ---------------------------------------------------------------------- |
| Структура общежития     | `DormitorySettingsDialog`, `StandardSectionsManager`                   |
| Вкладки и таблицы       | `CreateCustomTabDialog`, `CreateTableDialog`, `CustomTabOptionsEditor` |
| Столбцы                 | `ConfigurableColumns`                                                  |
| Строки и формулы        | `ReportTable`                                                          |
| Связи с таблицами       | `ReportLinkEditor`                                                     |
| Связи с размещением     | `PlaceLinkEditor`                                                      |
| Связь с персоналом      | `BindingDialog`                                                        |
| Блоки дашборда          | `WidgetDialog`                                                         |
| Статистика              | `StatisticsEditor`                                                     |
| Поля и карточки заездов | `arrivals/SettingsDialog`                                              |

Также охвачены блоки рабочей поверхности (`personnel/Dialogs/BlockDialog`,
`PersonnelWorkspaceBlock`) и свои списки (`EmployeeListFilterPanel`,
`personnel/Dialogs/SaveListDialog`).

Это прототипы основных задач, а не замена всех настроек рабочих компонентов.
Формулы в примере собираются из двух существующих строк. Для статистики
используется фиксированная неделя 25–31 октября 2026 года. Ручные значения
ячеек показывают механику ввода и сбрасываются при переключении примера.

Проверка: `npm run test -- src/pages/constructor-lab/ConstructorLab.test.tsx`,
затем `npm run build` из `app/frontend`.
