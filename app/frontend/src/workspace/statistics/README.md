# Статистика

`/cabinet/statistics` — список сохранённых отчётов; `/cabinet/statistics/:reportId` — отчёт и конструктор его блоков. Тестовый макет `/preview/statistics` остаётся отдельным экраном.

Определения отчётов и блоков хранятся в PostgreSQL (`0022_statistics_reports`), результаты рассчитываются заново при открытии, смене периода, возвращении в окно и раз в минуту. Личные отчёты доступны только автору. Общие доступны всем активным пользователям; менять доступ и удалять отчёт может автор. Сохранение проверяет `revision` под блокировкой строки: конфликт возвращает 409, черновик остаётся в редакторе.

Источники: строки большого отчёта с существующими формулами и связями, показатели мест, стандартные и пользовательские таблицы. Таблицы поддерживают количество строк, сумму числового столбца, дату события, накопление до даты и условие «равно» / «заполнено» по столбцу. Итог периода: сумма дневных значений, среднее за календарный день, последнее значение или максимум. Виды: число, линия, столбцы, области, круговая диаграмма и матрица общежитий по датам.

Все блоки открытого отчёта занимают полную ширину рабочей области. Графики подстраиваются под её размер; полные названия общежитий показаны под каждой точкой или столбцом. Когда места для подписей недостаточно, прокручивается сам график. Широкие таблицы также прокручиваются внутри блока; длинные названия общежитий переносятся в закреплённом первом столбце. Значения отображаются с округлением до целого, без изменения точности расчётов.

Каталог загружается из актуальных вкладок, строк и столбцов, включая иерархию пользовательских вкладок. Обновление каталога не сбрасывает черновик. Первое общежитие служит образцом; другие источники подбираются по названию строки, пути вкладки, названию и типу столбца. Варианты списков сопоставляются по подписи, а не по локальному ID. Найденные при сохранении связи закрепляются по ID. Для различающейся структуры можно явно задать источник каждого общежития. При режиме «все» новые общежития подбираются и включаются при расчёте автоматически.

Отсутствующие, удалённые и неоднозначные источники дают `null` с объяснением, без частичной суммы. Пустая строка большого отчёта отличается от введённого нуля. Будущие даты отображаются прочерками и не включаются в расчёт; календарь — Москва. Период ограничен 366 календарными днями, отчёт — 40 блоками.

Исторические значения доступны там, где их хранит источник. Таблица без выбранного столбца даты показывает текущее состояние на каждой дате; это явно указано в конструкторе. Редактор не выполняет произвольный SQL, объединения таблиц и новые формулы: вычисляемый показатель можно задать существующей формулой строки большого отчёта и использовать её как источник.

Проверки: `tests/test_statistics_reports.py` на сервере, `Statistics.test.tsx` в интерфейсе; они покрывают доступ, версии, реальные расчёты, автоматический каталог, устойчивость ID, пропуски и отмену устаревшего предпросмотра.
