# Подключение данных дашборда

`Dashboard` использует `GET /api/dashboard?from=…&to=…` за включительный период не длиннее года. Сервер получает полный список общежитий и рассчитывает значения обязательных формульных строк «Выход Итого», «Проживает Итого», «Текучка Итого» тем же способом, что и большой отчёт. Поэтому вновь созданные общежития автоматически входят в сводку.

`loadDashboard(range, signal)` передаёт период и сигнал отмены в API. Карточки проживающих, выхода и текучки показывают срез на конец периода; в текущем месяце дата среза ограничена сегодняшним днём по часовому поясу Москвы. Будущие дни в график не попадают.

Выбор общежития в блоке «Динамика показателей» передаёт необязательный `dormitory_id`. Он ограничивает только дневные серии графика; общие карточки, разбивка и список клиентов всегда охватывают все общежития.

- `dormitories`: полный список общежитий с постоянными ID. `residents`, `attendance`, `turnover` — срез на дату `snapshotDate`; `vacancies` пока не подключены.
- `clients`: выход на работу, сгруппированный по названию клиента; если клиенту принадлежат несколько общежитий, их значения суммируются.
- `totals`: общий выход и количество проживающих на ту же дату. Не суммировать дневную численность проживающих и выход за весь месяц.
- `turnover`: значение обязательной строки «Текучка Итого» на дату среза в карточке и за каждый день на графике.
- `daily`: одна запись на календарный день, показатели по всем общежитиям. Начальная формула обязательных строк `=0` тоже даёт ноль до настройки. `null` означает отсутствующую строку или ошибку формулы. График фильтрует диапазон включительно и не соединяет точки через пропуски.
- Не выдавать частичную сумму за общую, если по части общежитий нет данных. В таком случае передавать `null` до появления отдельного признака полноты.
- Календарь — `Europe/Moscow`, единый для текущего месяца и текущего дня (`dates.ts`).

## Доработать после готовности отчётов

Блок «Сохранение отчётов сегодня» намеренно не назначает красные/зелёные статусы. Сейчас он показывает будущий список и нейтральное состояние. После реализации отчётов нужно получить серверный признак сохранения за текущий московский день для каждого общежития: зелёный — есть сохранение сегодня, красный — нет. Сетевую ошибку или отсутствие подключения нельзя трактовать как красный статус. Этот блок относится к сегодняшнему дню независимо от выбранного периода графика.

Тестовые записи есть только в `*.test.tsx`; они не загружаются в приложение и не создаются в базе.
