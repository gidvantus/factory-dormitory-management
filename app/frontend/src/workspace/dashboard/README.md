# Подключение данных дашборда

`Dashboard` уже поддерживает общий включительный период, проверку дат, сброс на текущий месяц, выбор любых из трёх показателей графика, состояния загрузки/ошибки и отмену устаревших запросов. `loadDashboard` в `data.ts` пока возвращает пустые данные: API общежитий и отчётов ещё нет. В рабочем интерфейсе демонстрационные записи не используются.

Когда появятся отчёты, заменить реализацию `loadDashboard(range, signal)` обращением к API с параметрами `from` и `to` и передать `signal` в `fetch`. Контракт результата — `DashboardData` в `data.ts`. Менять разметку карточек и графика для этого не требуется.

- `dormitories`: полный список общежитий с постоянными ID. `residents`, `attendance`, `vacancies` — срез на конец периода; для текущего месяца — на сегодняшний день, без подстановки будущих значений. `snapshotDate` — фактическая дата среза.
- `totals`: общий выход и количество проживающих на ту же дату. Не суммировать дневную численность проживающих и выход за весь месяц.
- `turnover`: отдельная категория из строк отчётов (например, вахтовик сбежал). Не выводить из заселений/выселений. В карточках — значение за период, на графике — за каждый день. Уникальность людей и повторные события должны определяться будущей моделью отчёта.
- `daily`: одна запись на календарный день, показатели по всем общежитиям. `0` — подтверждённый ноль; `null` или пропущенный день — отсутствие сведений. График фильтрует диапазон включительно и не соединяет точки через пропуски.
- Не выдавать частичную сумму за общую, если по части общежитий нет данных. В таком случае передавать `null` до появления отдельного признака полноты.
- Календарь — `Europe/Moscow`, единый для текущего месяца и текущего дня (`dates.ts`).

## Доработать после готовности отчётов

Блок «Сохранение отчётов сегодня» намеренно не назначает красные/зелёные статусы. Сейчас он показывает будущий список и нейтральное состояние. После реализации отчётов нужно получить серверный признак сохранения за текущий московский день для каждого общежития: зелёный — есть сохранение сегодня, красный — нет. Сетевую ошибку или отсутствие подключения нельзя трактовать как красный статус. Этот блок относится к сегодняшнему дню независимо от выбранного периода графика.

Тестовые записи есть только в `*.test.tsx`; они не загружаются в приложение и не создаются в базе.
