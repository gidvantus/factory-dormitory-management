# Дизайн-система «Домовой»

Контракт оформления. Значения живут в одном месте — `:root` в `src/index.css`;
этот документ описывает, как ими пользоваться. Правило проекта:

> **Новое значение сначала токен.** Прежде чем писать в CSS или в модуле число
> или цвет, проверь, есть ли для него роль в `:root`. Если роли нет и значение
> действительно нужно интерфейсу — сначала добавь именованный токен в
> `src/index.css`, потом используй его. Объявлять токены в `*.module.css`
> запрещено: это проверяет `src/design-system.test.ts`.

## 1. Слои токенов

Токены делятся на три слоя. Слой может ссылаться только на слой ниже себя.

| Слой          | Что это                                            | Примеры                                                                                         |
| ------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 1. Примитивы  | сырые значения, без смысла                         | `--cream-50`, `--ink-900`, `--mint-600`, `--clay-700`, `--butter-700`                           |
| 2. Семантика  | роль в интерфейсе, ссылается на примитив           | `--color-bg-surface`, `--color-text-body`, `--color-danger`, `--color-status-ok`                |
| 3. Компоненты | готовые детали, ссылаются на семантику и примитивы | `.btn`, `.tag`, `.avatar`, `.panel`, `.data-table`, `.page-head`, `.toolbar`, `.dialog-actions` |

Требования к слоям:

- Компонент берёт цвет и размер **только через токен**, никогда — через
  сырое значение и никогда — через значение из `*.module.css`.
- Слой 1 не зависит ни от чего. Слой 2 ссылается на слой 1. Слой 3 ссылается
  на слои 1 и 2. Цепочка `var()` внутри `:root` не длиннее пяти переходов:
  это ограничение проверяет `src/design-tokens.test.ts`.
- Контраст текстовых ролей (`--color-text`, `--color-text-body`,
  `--color-text-muted`, `--color-danger`) нормирован WCAG 2.1 AA (не ниже
  4,5:1) и тоже проверяется `src/design-tokens.test.ts`.
- `--color-text-subtle` — исключение по смыслу: это цвет служебных иконок и
  разделителей, а не текста. Писать им текст нельзя.

## 2. Сетка вёрстки

### Лендинг

- Контейнер: `--container: 1140px`.
- Боковой отступ: `--gutter: clamp(1.125rem, 0.6rem + 2vw, 2rem)`.
- Вертикальный шаг секции: `--section-y: clamp(3.5rem, 2rem + 6vw, 7rem)`.
- Точки перелома лендинга: **1024px**, **768px**, **560px** (плюс служебная
  769px — граница, на которой карточки ролей выравнивают заголовки).

### Рабочее пространство (кабинет)

- Сайдбар: **248px** фиксированной ширины; на экранах до 1100px — 220px;
  до 760px сайдбар уезжает за край и открывается кнопкой `.shell .menu-toggle`.
- Колонка контента: `max-width: 1600px`, центр по горизонтали.
- Внутренние отступы контента: **36px** сверху, **40px** по бокам, **48px**
  снизу; на экранах шире 1700px верхний отступ — 44px; на экранах до 1100px —
  единый 28px; до 760px — 26px сверху, 20px по бокам, 36px снизу.
- Верхняя панель: 76px (68px до 760px), боковой отступ 40px (28px до 1100px,
  20px до 760px).
- Точки перелома кабинета: **1700px**, **1100px**, **760px**.
- Шаг плотности в пикселях: `--gap-2`, `--gap-4`, `--gap-6`, `--gap-8`,
  `--gap-10`, `--gap-12`, `--gap-14`, `--gap-16`, `--gap-18`, `--gap-20`,
  `--gap-24`, `--gap-28`. Лендинговый ритм остаётся на `--space-1 … --space-7`
  в rem; шкалы не смешиваются.

## 3. Типографическая шкала

Семейства: `--font-display` (Nunito) для заголовков и кнопок, `--font-body`
(Nunito Sans) для текста. Междустрочные интервалы: `--leading-tight: 1.1`,
`--leading-snug: 1.25`, `--leading-body: 1.65`.

### Лендинговая шкала

| Токен         | Значение                                     | Роль                                   |
| ------------- | -------------------------------------------- | -------------------------------------- |
| `--text-hero` | `clamp(2.125rem, 1.1rem + 3.4vw, 3.5rem)`    | заголовок первого экрана               |
| `--text-h2`   | `clamp(1.625rem, 1.15rem + 1.7vw, 2.375rem)` | заголовок секции                       |
| `--text-h3`   | `clamp(1.125rem, 1rem + 0.4vw, 1.375rem)`    | заголовок карточки и модального окна   |
| `--text-h4`   | `1.0625rem`                                  | подзаголовок внутри карточки           |
| `--text-lead` | `clamp(1.0625rem, 1rem + 0.35vw, 1.1875rem)` | вводный абзац                          |
| `--text-body` | `1rem`                                       | основной текст                         |
| `--text-sm`   | `0.9375rem`                                  | подпись, текст кнопки, вторичный абзац |
| `--text-xs`   | `0.8125rem`                                  | сноска, метка, служебная подпись       |

### Плотная рабочая шкала

Кабинет считает размеры в пикселях и не сводится к лендинговой: плотная
шкала — самостоятельная и допустимая. Её значения:

| Размер | Роль                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 11px   | подпись под заголовком блока, метка серии, служебная сноска               |
| 12px   | вторичный текст таблицы и карточек, подпись поля периода                  |
| 13px   | основной текст кабинета, ячейка таблицы, текст кнопки компактного размера |
| 14px   | подзаголовок страницы, строка навигации                                   |
| 15px   | значение в строке профиля, заголовок хостела                              |
| 16px   | заголовок карточки, заголовок таблицы                                     |
| 17px   | заголовок месяца в разделе мест                                           |
| 20px   | заголовок раздела внутри страницы общежития                               |

Заголовок страницы кабинета — `clamp(23px, 2.2vw, 30px)` (`.shell h1`).

## 4. Матрица кнопок

Единственный источник вида кнопок — глобальный слой в `src/index.css`.
Модуль обязан выдать кнопке вариант и размер, а не собственные `border`,
`background`, `border-radius` или `outline`.

**Вариант × размер.** Строки — вариант, столбцы — размер.

| Вариант                               | Основной, 48px (`--control-h-lg`)   | Компактный, 39px (`--control-h-md`)         | Малый, 32px                                                      |
| ------------------------------------- | ----------------------------------- | ------------------------------------------- | ---------------------------------------------------------------- |
| Обычное действие `.btn--primary`      | `<button class="btn btn--primary">` | `<button class="btn btn--primary btn--sm">` | высота `--control-h-sm`, горизонтальный отступ `--control-px-sm` |
| Опасное действие `.btn--danger`       | `<button class="btn btn--danger">`  | `<button class="btn btn--danger btn--sm">`  | высота `--control-h-sm`, горизонтальный отступ `--control-px-sm` |
| Второстепенное действие `.btn--ghost` | `<button class="btn btn--ghost">`   | `<button class="btn btn--ghost btn--sm">`   | высота `--control-h-sm`, горизонтальный отступ `--control-px-sm` |

Горизонтальный отступ компактного размера — `--control-px-md: 15px`; малого —
`--control-px-sm: 13px`. `.btn--primary` — заливка `--color-accent`, текст
`--color-on-accent`. `.btn--danger` — заливка `--color-danger`, текст
`--color-text-on-accent`, hover — `--clay-700`. `.btn--ghost` — фон
`--color-bg-surface`, рамка `--color-border-strong`, текст `--color-text`,
hover — фон `--color-bg-alt`, рамка `--ink-900`.

**Состояния.** Состояния одинаковы для всех трёх вариантов.

| Состояние     | Как задаётся                                            | Что происходит                                                |
| ------------- | ------------------------------------------------------- | ------------------------------------------------------------- |
| default       | класс варианта                                          | базовый вид                                                   |
| hover         | `:hover:not(:disabled)`                                 | заливка темнее, подъём `translateY(-2px)`                     |
| active        | `:active:not(:disabled)`                                | подъём возвращается в 0, цвет не меняется                     |
| focus-visible | `.shell button:focus-visible`, `.shell a:focus-visible` | рамка `--focus-outline-width` цветом `--focus` с отступом 3px |
| disabled      | `disabled`                                              | прозрачность 0.6, курсор `not-allowed`                        |
| loading       | `aria-busy="true"` или `.btn--loading`                  | курсор `progress` и вращающийся индикатор `::after`           |

Полоса кнопок диалога — `.dialog-actions` (`display: flex;
justify-content: flex-end; gap: 10px`). Каждая кнопка внутри получает явный
вариант: `Отмена` — `btn btn--ghost`, подтверждение удаления — `btn btn--danger`.

Кабинет сбрасывает типографику и цвет у вложенных кнопок и ссылок, чтобы те
наследовали шрифт каркаса. Этот сброс не действует на `.btn` и `.link-button`:
оба глобальных класса объявлены одним классом, а селектор `.shell button` даёт
специфичность выше, поэтому в `Workspace.module.css` они исключены явной
оговоркой `:not(.btn):not(.link-button)`. Без неё вариант кнопки проигрывал бы
сбросу и заливка осталась бы без своего текстового цвета.

Дополнительные размеры одного и того же визуального варианта: `.btn--sm` —
компактный (39px, радиус `--radius-4xs`), `.btn--block` — на всю ширину.

## 5. Радиусы и статусные цвета

### Радиусы

| Токен           | Значение | Где применяется                                    |
| --------------- | -------- | -------------------------------------------------- |
| `--radius-xs`   | 6px      | ячейка-поле внутри таблицы, бейдж формулы          |
| `--radius-2xs`  | 7px      | компактная кнопка строки, чип ссылки               |
| `--radius-3xs`  | 8px      | кнопка диалога, кнопка-иконка                      |
| `--radius-4xs`  | 9px      | компактная кнопка `.btn--sm`, поле периода         |
| `--radius-5xs`  | 10px     | плитка шаблона, поле формы шаблона                 |
| `--radius-sm`   | 12px     | поле ввода, контейнер таблицы, плашка              |
| `--radius-md`   | 18px     | карточка, панель `.panel`, модальное окно карточки |
| `--radius-lg`   | 26px     | модальное окно лендинга, карточка лендинга         |
| `--radius-xl`   | 34px     | крупный декоративный блок лендинга                 |
| `--radius-pill` | 999px    | тег `.tag`, аватар, круглый значок                 |

Радиусы 6/7/8/9/10/11/12/13/14/16/18/99px сосуществуют намеренно: сводить их
к одной шкале — отдельный редизайн.

### Статусные цвета

| Токен                    | Значение          | Смысл                                    |
| ------------------------ | ----------------- | ---------------------------------------- |
| `--color-status-neutral` | `#909ba4`         | отчёт ещё не готов, состояние неизвестно |
| `--color-status-ok`      | `var(--mint-600)` | отчёт сохранён                           |
| `--color-status-missing` | `#c34d4d`         | отчёта нет                               |

Статус показывается точкой `.dashboard .statusDot` через `data-status` и
подписью рядом; цветом кодируется состояние, а не текст. Тег нейтрального
статуса — `.tag--neutral` (фон `--color-bg-tint`, текст `--color-text-body`);
подтверждённый статус — `.tag--ok`, ожидание — `.tag--wait`, выбытие —
`.tag--out`.

## 6. Каркас страницы

| Класс         | Назначение                                                                               |
| ------------- | ---------------------------------------------------------------------------------------- |
| `.page-head`  | шапка страницы: заголовок слева, действие справа, отступ снизу 28px                      |
| `.toolbar`    | полоса действий над таблицей: заголовок слева, кнопка справа, шаг 12px                   |
| `.panel`      | карточка-таблица: рамка `--color-border`, радиус `--radius-md`, фон `--color-bg-surface` |
| `.data-table` | таблица кабинета: паддинг 17px/20px, шапка 10px uppercase, зебра по hover                |

Аватар-инициалы — `.avatar` с модификатором размера: `.avatar--sm` (26px,
таблицы лендинга) и `.avatar--md` (32px, таблицы кабинета); тон задаётся
атрибутом `data-tone` (`mint`, `peach`, `lilac`).
